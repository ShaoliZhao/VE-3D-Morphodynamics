# Method

Four ordered landmarks define a tetrahedron. The scalar triple product is unchanged by translation and determinant-positive rotations, scales cubically with size and changes sign under reflection. Dividing by RMS radius cubed removes global scale.

Landmark ordering carries biological meaning and must be declared before evaluation. Suitable anchors include anterior and posterior domains plus two lineage-specific regions. Data-driven PCA axes are insufficient because eigenvector signs are arbitrary and can create apparent handedness flips.

Near-coplanar landmarks produce unstable signs. Report normalized volume magnitude, exclude signatures below a declared threshold and use several independent landmark tuples.
